# AI-WAF — Web Application Firewall wspomagany AI (czas rzeczywisty)

Specyfikacja systemu WAF, który łączy klasyczne reguły detekcji (OWASP CRS)
z modelami ML/AI do wykrywania i blokowania ataków webowych w czasie
rzeczywistym, przy niskim odsetku fałszywych pozytywów i niskim opóźnieniu
(inline, na ścieżce żądania).

Pełna specyfikacja: [SPEC.md](SPEC.md)
